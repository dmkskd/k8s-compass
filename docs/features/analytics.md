# Analytics

The Analytics tab provides a SQL query interface for exploring the DuckDB data directly.

## Overview

**Main Component:** `AnalyticsView.tsx`

**Layout:**
- Left sidebar: Preset queries and table schema browser
- Main area: SQL editor, results table, and optional chart visualization

## Data Loading

**This is the only tab that queries DuckDB directly with user-provided SQL.**

```typescript
// Execute arbitrary SQL
const result = await executeQuery<Record<string, unknown>>(sql)
```

All other tabs load data via hooks that run predefined queries.

## Search Behavior

**No global search** - the Analytics tab doesn't use the `searchQuery` from the store.

Instead, users write SQL with `WHERE` clauses:
```sql
SELECT * FROM 'keps.parquet' WHERE title ILIKE '%sidecar%'
```

## Features

### SQL Editor
- Syntax highlighting for SQL keywords and functions
- Auto-resize textarea
- Execute with button or Ctrl+Enter

### Preset Queries
- Grouped by category (Overview, Features, API Changes, etc.)
- Click to load query into editor
- Supports metadata comments:
  ```sql
  -- @name: Feature Count by Stage
  -- @description: Shows feature distribution
  -- @chart: bar
  -- @label: stage
  -- @value: count
  SELECT stage, COUNT(*) as count FROM ...
  ```

### Results Display
- Table view with sortable columns
- Row count and execution time
- Export to CSV (planned)

### Chart Visualization
- Auto-detected from query metadata or column names
- Chart types: bar, line, pie, grouped_bar, stacked_bar
- 2D (SVG) and 3D (Three.js) rendering options
- Stage-specific colors (stable=green, beta=amber, alpha=purple)

### Schema Browser
- ER diagram showing table relationships
- Click table to see columns with types
- PK/FK indicators
- Column descriptions from `schema_metadata.json`

## Query Metadata Format

Preset queries can include metadata comments:

```sql
-- @name: Query Title
-- @description: What this query shows
-- @chart: bar | line | pie | grouped_bar | stacked_bar
-- @label: column_name_for_labels
-- @value: column_name_for_values
-- @group: column_name_for_grouping (for grouped/stacked charts)
-- @orientation: horizontal | vertical
SELECT ...
```

## State Management

```typescript
// Local state only (no store integration)
{
  query: string,           // Current SQL
  result: QueryResult | null,
  error: Error | null,
  isExecuting: boolean,
  viewMode: 'table' | 'chart' | 'schema' | 'queries',
  chartConfig: ChartConfig,
  selectedTable: string | null,  // For schema browser
}
```

## Example Queries

### Cross-release feature search (workaround for Releases tab limitation)
```sql
SELECT f.version, k.kep, k.title, f.stage
FROM 'features.parquet' f
JOIN 'keps.parquet' k ON f.kep = k.kep
WHERE k.title ILIKE '%sidecar%'
ORDER BY f.version DESC
```

### API changes between versions
```sql
SELECT change_type, COUNT(*) as count
FROM 'api_diffs.parquet'
WHERE from_version = '1.34' AND to_version = '1.35'
GROUP BY change_type
```

### KEPs by SIG
```sql
SELECT sig, COUNT(*) as count
FROM 'keps.parquet'
GROUP BY sig
ORDER BY count DESC
```

## Preset Query Groups

Defined in `presetQueries.ts`:

1. **Overview** - High-level stats
2. **Features** - KEP analysis
3. **API Changes** - Schema diffs
4. **Security** - CVEs and fixes
5. **Content** - Learning resources
