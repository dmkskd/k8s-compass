# Control Plane

The Control Plane tab provides a 3D visualization of Kubernetes control plane architecture.

## Overview

**Main Component:** `ControlPlaneView.tsx`

**Layout:**
- 3D scene with control plane components (API Server, etcd, Controller Manager, Scheduler)
- Worker nodes with node components (kubelet, kube-proxy, containerd)
- Satellite components (CoreDNS, CNI, kubectl)
- Interactive component selection with detail panels

## Components Visualized

### Control Plane
- **kube-apiserver** - Central API endpoint
- **etcd** - Distributed key-value store
- **kube-controller-manager** - Runs controller loops
- **kube-scheduler** - Assigns pods to nodes

### Node Components
- **kubelet** - Node agent
- **kube-proxy** - Network proxy
- **containerd** - Container runtime

### Satellites
- **CoreDNS** - Cluster DNS
- **CNI** - Container Network Interface
- **kubectl** - CLI tool

### Special Views
- **Feature Gates** - Feature flags controlling experimental features

## Data Loading

Component data comes from multiple parquet tables:

```typescript
// Components and their flags
useComponentWithFlags(componentId)
  → components.parquet + component_flags.parquet

// kubectl commands
useKubectlCommands(version)
  → kubectl_commands.parquet

// Feature gates
useFeatureGates(version)
  → feature_gates.parquet
```

## ComponentSpec Modal

When clicking a component, a modal opens showing:

### For Components (kube-apiserver, kubelet, etc.)
- Component description and docs link
- CLI flags with search/filter
- Flag metadata (type, default, introduced/deprecated versions)
- Related KEPs

### For kubectl
- Command list with search
- Command details (synopsis, usage, options, examples)
- Subcommands

### For Feature Gates
- Feature gate list with stage filter (alpha/beta/stable/deprecated)
- Component filter (which components use the gate)
- Gate details (description, status, version history)
- Related KEP links

## State Management

```typescript
// Local state in ControlPlaneView
{
  selectedComponent: string | null,  // Currently selected component ID
  flowStep: number,                  // Animation step for data flow
}

// ComponentSpec local state
{
  searchQuery: string,
  filterType: 'all' | 'new' | 'deprecated',
  stageFilter: 'all' | 'alpha' | 'beta' | 'stable' | 'deprecated',
  componentFilter: string,  // For feature gates
  selectedCommand: string | null,  // For kubectl
  selectedGate: string | null,  // For feature gates
}
```

## Data Tables Used

| Table | Purpose | Generated By |
|-------|---------|--------------|
| `components` | Component metadata (id, type, description, docs_url) | `extract-component-flags` |
| `component_flags` | CLI flags per component | `extract-component-flags` |
| `kubectl_commands` | kubectl commands per version | `extract-kubectl` |
| `kubectl_options` | Command options/flags | `extract-kubectl` |
| `kubectl_examples` | Command examples | `extract-kubectl` |
| `feature_gates` | Feature gates per version with stage | `extract-feature-gates` |
| `keps` | KEP details for linking | `build-release` |

## 3D Visualization

- Uses Three.js via @react-three/fiber
- Components rendered as 3D shapes with icons
- Orbital camera controls (drag to rotate, scroll to zoom)
- Animated data flow lines between components
- Sparkle effects for visual interest
